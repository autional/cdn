Autional CDN (.com)

Versioned, immutable static assets for autional.com. Runtime assets only — build-time code goes through npm.

Paths are immutable. When content changes, publish a new version directory; files under a version path are cached forever. Read /ai/latest.json (short TTL) to follow the latest.

Layout

/ai/<version>/…    # AI skill distribution (text/markdown, plus .sha256)
/ui/<version>/…    # design-system runtime assets (CSS / icons / fonts)

Own domain: https://cdn.autional.com.
